# Sledding game

This game is a sledding game where you are going down a hill that is infinite.
The player is santa claus and colects gifts that are on the hill
Keep track of the number of gifts you have.
You get one point every second. If you hit any obstacle, then you die.
The three obstacles that can spawn in the map are trees, snowmans and rocks.
The game is first person you control the sled using the left and right arrow keys and you can jump by using the up arrow.
The ground is snow.

THe obstacles should not go up, they should only get bigger and they start at the top of the white background and slowly go down as they get bigger. If santa touches an obstacle, he dies (game over)
